## 6\. Estilo visual

- Fondo **blanco**, acentos en **colores pastel** (rosa \#F8D7E3, azul \#D7EAF8, verde \#E3F8D7, lila \#E8DFF5).  
- Layout **orgánico pero claro**: formas suaves de fondo (blobs), tarjetas con esquinas redondeadas, algo de asimetría, pero siempre fácil de leer.  
- Tipografía sans-serif moderna (Inter o similar). Titulares con algo más de personalidad.  
- Sensación: profesional y cercana. Tiene que parecer seria para un recruiter de consultoría, pero con personalidad.  
- Animaciones sutiles al hacer scroll (fade-in), nada más.

## 7\. Requisitos técnicos

- HTML \+ CSS \+ JavaScript simple (sin frameworks pesados), o Tailwind si simplifica.  
- Textos de los dos idiomas en un archivo aparte (`i18n.js` o JSON) para editarlos fácilmente.  
- Responsive, pensado primero para móvil.  
- Accesible: contraste suficiente, `alt` en imágenes, navegación con teclado.  
- SEO básico: `title`, meta description, Open Graph (para que se vea bien al compartir el enlace en LinkedIn).  
- Desplegable gratis en GitHub Pages, Netlify o Vercel.
